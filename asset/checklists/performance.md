# 评审清单 · performance

- [ ] BLOCK 先测量后优化：有 cProfile/py-spy 或 timeit 基线与改后对比
- [ ] 报告含环境（版本/平台/核数）、数据规模、重复次数或方差
- [ ] BLOCK 未测就给出的加速倍数已删除
- [ ] 算法级改动优先于常数级微调
- [ ] 循环内热点已消除（全局/属性查找别名、join 拼接、re 预编译）
- [ ] CPU-bound 热点给出 numpy/Cython/C 扩展方案与纯 Python 回退
- [ ] 内存：流式读取、生成器、slots/array，无整文件 read() 于大文件
- [ ] I/O 批量写、连接复用、超时与重试上限齐备
- [ ] 缓存命中/失效策略明确，无无界缓存
- [ ] 启动开销（import 期 I/O、重依赖延迟导入）已评估
