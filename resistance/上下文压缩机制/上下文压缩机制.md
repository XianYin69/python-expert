# 上下文压缩机制

## 规则
1. 证据层（诊断输出、抓取正文）落文件，会话内只保留路径与摘要行。
2. 交付前压缩为结论层：判定 + 依据路径 + 建议编号，细节由调用方按需读文件。
3. 长清单只列 fail 与 need-data 项，pass 项以计数表示。
4. 多轮会话每轮重述「会话基线」（Python 版本、可用工具、授权范围），不重述历史推理。
5. 压缩不得删除边界声明与未覆盖声明。

## 违反后果
上下文溢出、结论与证据脱钩、复核成本转嫁给调用方。
