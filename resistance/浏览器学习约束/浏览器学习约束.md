# 浏览器学习约束

本约束规定 [浏览器学习](../../branch/流程/浏览器学习/浏览器学习.md) 横切节点的强制边界。

## 必须

1. 命中触发条件（不明白的语法/库/性能/工程实践）时**先检索学习、后作答**，不得跳过。
2. 联网动作一律经 `file_ops`（`local:skill_manage_system`）的 `ff_lite.py search|fetch`，
   调用方须已 `:grant network`；本技能不自行发起网络请求、不装浏览器依赖。
3. 只向 `file_ops` 传**意图 + 参数**，不内嵌正文、不代写其执行逻辑。
4. 每条 `[联网]` 必须带真实 URL + 站点 + 确证日期，且该 URL 出自本次检索命中或 fetch 成功结果。
5. 检索词遵循可达性规则：优先中文书名或「单词 + 出版社」；避免 ≥4 词英文书名（词典页污染）。
6. 境外源 `fetch` 失败（`WinError 10060`）即改投可达源：`book.douban.com`、知乎、
   `*.github.io` 中文镜像、docs.python.org、peps.python.org。
7. 学习所得写回 `asset/knowledge/` 条目或 [参考书目](../../references/参考书目/参考书目.md)，
   并落一条逻辑链（证据→结论→取舍→边界）。

## 禁止

1. 禁止臆造 URL、凭记忆填书号、把未确证条目标为 `[联网]`。
2. 禁止用搜索引擎首页/词典页/下载站链接充当权威出处。
3. 禁止把 `[本地]` 未确证结论写成「已验证」；须显式声明未经联网确证。
4. 禁止写入或修改 `file_ops`、`skill_manage_system` 等他人技能目录。
5. 禁止把抓取缓存落进本技能目录（红线：缓存不入 skill 目录）。

## 违反后果

- 臆造出处 → 结论不可追溯，评审与调用方全部失效，触发 [审查约束](../审查约束/审查约束.md) 不合格。
- 跳过学习 → 凭记忆作答，版本差异与废弃项误导调用方，记 [惩罚机制](../惩罚机制/惩罚机制.md) 重试。
- 缓存入库 → 污染提交历史，违反 [垃圾回收机制](../垃圾回收机制/垃圾回收机制.md)。
