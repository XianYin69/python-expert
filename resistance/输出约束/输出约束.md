# 输出约束

## 必须

1. 固定六段结构（由 `scripts/advice_compose.py` 生成）：
   结论 → 事实 → 判断 → 清单核对 → 改动建议 → 未覆盖与后续实验。
2. 每条判断四要素齐全：判定 / 依据 / 取舍 / 边界。
3. 每条建议四要素齐全：现状 / 改法 / 验证命令 / 回滚方式。
4. 面向调用方裁剪：SMS 主流程给「结论+建议」；编码技能给全文含命令原文。
5. 代码片段可复制运行，标注 Python 版本与依赖。

## 禁止

1. 省略「未覆盖」段造成虚假完备。
2. 输出无出处的规则编号（如凭空引用某 ruff 码）。
3. 一次给出覆盖式重写方案（除非调用方明确要求重构）。
4. 把风格偏好写成强制要求。
5. 在交付文本中夹带临时缓存路径或抓取原始 HTML。

## 长度

- 结论 ≤5 条；建议 ≤7 条；单条 ≤3 行正文 + 必要代码。

## 兜底

信息不足 → 输出「需补充清单」+ 条件式判断（if-then），不得编造事实填空。
