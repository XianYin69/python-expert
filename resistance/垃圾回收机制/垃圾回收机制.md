# 垃圾回收机制

## 规则
1. 工作产物只落工作区 tmp/（env SMS_TMP），禁止写入 skill 目录。
2. 收尾时清理 .tmp/.bak/.log/.part/.download、__pycache__/、空目录、超 3 天的抓取缓存。
3. 预览优先：garbage_collect.py --path <tmp> --dry-run 确认后再执行。
4. 技能资产（knowledge、checklists、templates）不属于垃圾，禁止回收。
5. 交付前核对：技能包内不得残留抓取 HTML、provenance 缓存、临时 verdict json。

## 违反后果
技能包污染、体积膨胀、缓存与本体混淆导致 SMS 安装检查失败。
