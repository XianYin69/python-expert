# 过程链存取

## 规则
1. 每步完成即存档：process_chain.py save --step <节点名> --data '<json>'。
2. 存档内容：输入形态、所用脚本、输出物路径、下一步判定。
3. 异常走 interrupt --step <节点>，修复后 resume，禁止静默跳步。
4. 跨会话续作用 load --step <节点> 恢复基线，不凭记忆重推。
5. 存档落用户缓存目录，不写 skill 目录、不随技能包交付。

## 违反后果
中断后无法返回正确节点，重复取证浪费预算，交付缺执行凭证。
