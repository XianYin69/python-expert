# 沙盒机制

## 规则
1. 未指定目标工作目录时在固定路径建沙盒作业（SG_SANDBOX_HOME → 缓存目录 → 根目录）。
2. 本技能默认工作区为 env SMS_TMP 下的 tmp/，产物一律先落沙盒再交付。
3. 交付：sandbox.py deliver --id <沙盒> --to <目标> 先预览，确认后 --yes 复制；随后 clean。
4. 目标目录非空则拒绝覆盖，须由调用方显式指示。
5. 红线：不得写入或改动其他既有技能目录（general-programming / code-guidelines / pavedpath-code 等）。

## 违反后果
污染既有技能、交付不可回滚、沙盒残留被误当资产入库。
