# 约束部分（红线区识别）

## 何为红线区

命中任一条件即视为红线区，动作须显式授权或走兜底：

1. 写盘：修改用户代码、既有技能目录、系统解释器环境。
2. 执行不可信代码：`eval/exec/pickle/yaml.load` 相关调试请求。
3. 网络与安装：`pip/uv/poetry install`、下载依赖、上传片段。
4. 破坏性命令：`rm -rf`、`git reset --hard`、数据库迁移、清缓存。
5. 凭据：读取或写入 token/密码/私钥。

## 处置

- 默认只读评审；红线区动作先 `--dry-run` 预览，再等调用方确认。
- 未授权时改为「给出命令原文 + 预期影响」，由调用方执行。
- 每次红线决策写逻辑链（`logic_chain.py add`）。

## 与既有技能边界

本技能只输出判断与建议，**不得**修改 general-programming / code-guidelines / pavedpath-code 等
既有技能目录；跨技能改动由 SMS 主流程调度并单独授权。
