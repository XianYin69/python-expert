# 逻辑链机制

## 规则
1. 每条专家结论落一条链：logic_chain.py add --from <证据> --to <结论> --why <取舍>。
2. 链文件写用户缓存目录（LOCALAPPDATA/Skill_Generator/chains/），禁止写 skill 目录。
3. 交付前 verify，无依据的结论删除或降级为「存疑需实验」。
4. 决策岔路（选型冲突、重构粒度）先 debate 正反双链再裁决。
5. 链是复核凭证：调用方质疑任一结论时，按链回溯到诊断行或知识条目。

## 违反后果
结论不可追溯，评审退化为个人意见，无法被 SMS 或其他技能复核。
