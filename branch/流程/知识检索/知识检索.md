# 知识检索

## 目的

按定位结果取回权威条目（规则、判据、阈值、API 边界），不凭记忆作答。

## 动作

1. `python scripts/knowledge_index.py --topic <方向> [--query <词>] [--json]`
   列出 `asset/knowledge/` 下匹配条目与来源。
2. 只读命中条目正文；条目内 `来源` 行为权威出处（PEP/官方文档/权威书目）。
3. 条目冲突时按 [知识树](../../../references/知识树/知识树.md) 的优先级：
   官方文档/PEP > 权威书目 > 社区共识 > 个人风格偏好。
4. 无匹配条目 → 记 `process_chain.py interrupt`，走 [经验查询] 式补录（联网来源须白名单），
   不得以未标注来源的断言交付。

## 输出

`证据集`：条目路径 + 关键判据摘录 + 出处。
