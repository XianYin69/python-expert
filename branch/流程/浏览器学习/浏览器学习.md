# 浏览器学习（Browser Learning）

横切节点：不属于主链任一步，凡命中触发条件即在**任一步内部**插入执行。

## 触发条件

出现以下任一情形，**必须**先学习再作答，禁止凭记忆直接回答：

1. 不确定的 Python 语法/语义（新 PEP、版本差异、3.13 free-threading 等）。
2. 不熟悉的库、API 签名、废弃项或迁移路径。
3. 无实测依据的性能/复杂度说法（加速倍数、GIL 行为边界）。
4. 工程实践争议项（打包、类型标注策略、测试组织）需权威出处支撑。

## 强制流程

1. 派 `file_ops` 联网检索（见 [dependence](../../../dependence/dependence.md)）：只传**意图 + 参数**，
   不内嵌正文——`search "<关键词>" [n]`，需要正文再 `fetch <url>`。
2. 检索词规则：≥4 词英文书名会被搜索引擎切成词典页，改用**中文书名**或「**单词 + 出版社**」。
3. 可达性：本机在大陆，境外站点 fetch 会 `WinError 10060`；优先可达源
   （`book.douban.com`、知乎、`*.github.io` 中文镜像、docs.python.org、peps.python.org）。
4. 取到条目后落**出处**：URL + 站点 + 检索日期；未确证的一律标 `[本地]`，**严禁臆造 URL**。
5. 学习结论写回对应知识条目（`asset/knowledge/`）或 [知识树](../../../references/知识树/知识树.md)
   来源留痕，并记逻辑链（证据→结论→取舍→边界）。

## 输出格式

```
结论：<可执行判断>
出处：<URL>（[联网] 已确证 / [本地] 未确证）
取证：search "<词>" → 命中 n 条 · 可达性 <ok/10060>
边界：<适用版本与场景>
未覆盖：<仍未确证的部分>
```

## 降级

- `network` 未授权或全部源不可达 → 记 `process_chain.py interrupt`，本轮答案整体标 `[本地]`
  并显式声明「未经联网确证」，不得伪装成已确证。
- 重试达惩罚机制上限 → 熔断并回调用方（见 [惩罚机制](../../../resistance/惩罚机制/惩罚机制.md)）。
