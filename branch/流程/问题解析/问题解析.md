# 问题解析

## 输入

代码片段 / 报错栈 / 设计问题 / 评审请求（PR、模块）/ 性能现象。

## 动作

1. 归类问题类型：`style | typing | structure | algorithm | concurrency | error | logging | test | packaging | perf | security | design`。
2. 抽取硬事实：Python 版本、运行环境、依赖清单、可复现步骤、期望与实际的差异。
3. 缺 Python 版本或依赖信息 → 先跑 `scripts/env_probe.py` 取证，不得假设。
4. 判定问题边界：单函数级 / 模块级 / 架构级，决定后续建议粒度。

## 输出

`问题卡`：类型 + 事实 + 边界 + 未决问题（≤5 条）。

## 降级

无代码只有描述 → 只给「需补充信息清单」与条件式判断（if-then），不编造行号。
