# 取证探查

## 目的

用脚本取得本机事实，替代猜测。按方向选脚本，可并行。

## 脚本映射

| 方向 | 脚本 |
|---|---|
| 环境/依赖 | `scripts/env_probe.py` |
| 风格/类型 | `scripts/style_probe.py` |
| 安全/反模式 | `scripts/security_scan.py` |
| 测试/覆盖率 | `scripts/test_probe.py` |
| 性能 | `scripts/perf_probe.py` |
| 并发 | `scripts/concurrency_probe.py` |
| 数据结构/算法 | `scripts/complexity_audit.py` |
| 打包 | `scripts/packaging_probe.py` |

## 动作

1. 一律 `--dry-run` 优先；探查脚本只读，不改目标文件。
2. 采集输出为事实清单（文件:行 + 规则号 + 严重度）。
3. 任一脚本异常 → `process_chain.py interrupt --step 取证探查`，修复后 `resume`。

## 输出

`事实表`：可复现的原始诊断行，不含结论。

## 红线

禁止把「未运行」的结果写成「已验证」；禁止为凑结论伪造数字。
