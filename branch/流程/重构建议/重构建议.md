# 重构建议

## 目的

给出**最小可执行**改动方案，而非理想化重写。

## 动作

1. 按「阻塞项优先、改动面从小到大」排序建议，每条含：
   `现状 → 目标 → 改法（代码级） → 验证方式 → 回滚方式`。
2. 每条建议必须可被单条测试或诊断命令验证（引用 `scripts/` 命令原文）。
3. 结构性重构给出分步迁移顺序（ strangler：先加适配层→再迁调用方→最后删旧路）。
4. 需要新增依赖时，先查 [dependence](../../../dependence/dependence.md) 与
   `scripts/packaging_probe.py`，声明版本约束与许可证影响。
5. 模板产出用 `scripts/template_gen.py --kind pyproject|conftest|protocol|worker`。

## 输出

`建议集`：有序改动清单（≤7 条，与裁决集一一对应）。

## 红线

禁止一次建议覆盖式重写；禁止无验证方式的建议；禁止引入未声明依赖。
