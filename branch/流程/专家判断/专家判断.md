# 专家判断

## 目的

把证据集 + 事实表转成**可执行**结论：判定 + 依据 + 取舍 + 边界。

## 判断格式（每条结论必填）

1. `判定`：保留 / 修改 / 必须改（阻塞）/ 存疑需实验。
2. `依据`：知识条目路径或诊断行（PEP/官方文档/实测数据）。
3. `取舍`：为什么选它、放弃了什么替代方案、代价。
4. `边界`：结论在什么条件下失效（版本、规模、GIL、平台）。

## 动作

1. 先量化再定性：性能问题必须有 `scripts/perf_probe.py` 数据；无数据则标「存疑需实验」。
2. 冲突约束按 [评审约束](../../../resistance/评审约束/评审约束.md) 的仲裁优先级裁决。
3. 每条结论落逻辑链：`logic_chain.py add --from 证据 --to 结论 --why 取舍`。
4. 结论数 ≤7 条，按影响面排序；超出则合并同类项。

## 输出

`裁决集`（供 [输出交付](../输出交付/输出交付.md) 组装）。

## 红线

不得把偏好当结论；不得在无实测数据时给出具体加速倍数。
