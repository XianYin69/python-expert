# 输出交付

## 目的

把裁决集 + 清单结果 + 建议集组装成固定格式，供 SMS 与其他编码技能直接消费。

## 动作

1. `python scripts/advice_compose.py --topic <方向> --verdict <裁决.json> [--out md]`
   生成标准结构：
   ```
   ## 结论（TL;DR）
   ## 事实（诊断行/数据）
   ## 判断（判定·依据·取舍·边界）
   ## 清单核对（pass/fail/n-a/need-data）
   ## 改动建议（有序·可验证·可回滚）
   ## 未覆盖与后续实验
   ```
2. 面向调用方裁剪：SMS 主流程要短（结论+建议）；编码技能要全（含清单与命令）。
3. 所有数字必须可追溯到事实表；不可追溯的删除。

## 输出

交付文本 + 可选 `tmp/advice.md`（工作区，不入 skill 目录）。

## 红线

不得省略「边界」与「未覆盖」；不得输出无出处的规则编号。
