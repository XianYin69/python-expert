# 评审清单

## 目的

按方向逐项核对，保证评审无遗漏、可复核。

## 动作

1. `python scripts/review_checklist.py --topic <方向> [--format md|json]`
   输出该方向全部检查项（编号 + 判据 + 严重度）。
2. 逐项标注：`pass | fail | n/a | need-data`，`fail` 必须回链到事实表行号。
3. 阻塞项（blocking）任一 `fail` → 评审结论为「不可合并」，写入裁决集首条。
4. 全 `pass` 也须列出「本轮未覆盖范围」，避免虚假完备感。

## 输出

`清单结果`：逐项状态 + 未覆盖声明。

## 清单来源

`asset/checklists/` 九份方向清单（与知识树一一对应），条目变更须同步知识树。
