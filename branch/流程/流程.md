# 流程（Process）

python-expert 的执行流程细则，每个步骤独立成文件夹。

## 单一路径（顾问型）

```
[初始化/](初始化/初始化.md) → [问题解析/](问题解析/问题解析.md) → [领域定位/](领域定位/领域定位.md) →
[知识检索/](知识检索/知识检索.md) → [取证探查/](取证探查/取证探查.md) → [专家判断/](专家判断/专家判断.md) →
[评审清单/](评审清单/评审清单.md) → [重构建议/](重构建议/重构建议.md) → [输出交付/](输出交付/输出交付.md) →
[收尾/](收尾/收尾.md) → 完成
```

横切：[浏览器学习/](浏览器学习/浏览器学习.md) 不占主链位次，任一步命中不明白项即插入执行。

## 步骤列表

| 步骤 | 路径 | 说明 |
|---|---|---|
| 初始化 | [初始化/](初始化/初始化.md) | 载入知识树、确认调用方与取证范围 |
| 问题解析 | [问题解析/](问题解析/问题解析.md) | 抽取代码/需求/报错，界定问题类型 |
| 领域定位 | [领域定位/](领域定位/领域定位.md) | `scripts/classify_topic.py` 映射到子方向 |
| 知识检索 | [知识检索/](知识检索/知识检索.md) | `scripts/knowledge_index.py` 取对应知识条目 |
| 取证探查 | [取证探查/](取证探查/取证探查.md) | 运行对应 probe 脚本取得本机事实 |
| 专家判断 | [专家判断/](专家判断/专家判断.md) | 给出可执行结论（含取舍与边界条件） |
| 评审清单 | [评审清单/](评审清单/评审清单.md) | `scripts/review_checklist.py` 逐项核对 |
| 重构建议 | [重构建议/](重构建议/重构建议.md) | 最小改动方案 + 迁移顺序 + 风险 |
| 输出交付 | [输出交付/](输出交付/输出交付.md) | `scripts/advice_compose.py` 出标准裁决格式 |
| 收尾 | [收尾/](收尾/收尾.md) | 垃圾回收、链存档、返回调用方 |
| 浏览器学习（横切） | [浏览器学习/](浏览器学习/浏览器学习.md) | 不明白项先检索学习并给出出处 |
