# 收尾

## 目的

释放工作产物、存档链路、返回调用方（SMS 主流程继续整合）。

## 动作

1. 垃圾回收：`python garbage_collect.py --path <工作区 tmp> --dry-run` 预览后执行，
   临时产物只清工作区，**不得**删除 skill 目录内资产。
2. 过程链存档：`process_chain.py save --step 收尾`；中断未闭合则 `interrupt` 记录原因。
3. 逻辑链校验：`logic_chain.py verify <chain.jsonl>`，悬空结论回补依据。
4. 上下文压缩：长会话交付前只保留结论层，证据层落文件路径引用。
5. 返回：向调用方输出交付文本 + 产物绝对路径，标记「完成」。

## 输出

`完成`：交付摘要、产物路径、未闭合风险清单。

## 红线

收尾后不进入修改流程；未回收的工作区临时文件不得随技能包交付。
