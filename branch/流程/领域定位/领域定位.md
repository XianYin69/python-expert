# 领域定位

## 目的

把问题卡映射到知识树子方向，允许多标签（≤3 个主标签）。

## 动作

1. 运行：`python scripts/classify_topic.py --text "<问题描述>" [--code path.py]`
   输出候选子方向与命中关键词。
2. 主标签取权重最高者；跨域问题（并发×性能、测试×打包）保留次标签并行检索。
3. 子方向集合固定为知识树八叶，不得临时发明新叶；确属新领域 → 记中断并回 [知识检索](../知识检索/知识检索.md) 补叶。

## 输出

`定位结果`：主方向 + 次方向 + 命中的知识条目路径列表。

## 八叶

style-typing / data-structures / algorithms / concurrency-async / errors-logging / testing / packaging-deps / performance / security-antipattern（详见 [知识树](../../../references/知识树/知识树.md)）。
