# 领域定位

## 目的

把问题卡映射到知识树子方向，允许多标签（≤3 个主标签）。

## 动作

1. 运行：`python scripts/classify_topic.py --text "<问题描述>" [--code path.py]`
   输出候选子方向与命中关键词。
2. 主标签取权重最高者；跨域问题（并发×性能、测试×打包）保留次标签并行检索。
3. 子方向集合固定为知识树九叶，不得临时发明新叶；确属新领域 → 记中断并回
   [知识检索](../知识检索/知识检索.md) 补叶。

## 越界路由（不属于本技能九叶时）

| 问题域 | 转交 |
|---|---|
| Web 框架/前端集成 | frontend-dev / web-design-guidelines |
| 数据库与 SQL 建模 | database-management |
| 并发架构选型（跨服务） | concurrency-design |
| 通用编码规范落地 | code-guidelines / general-programming |
| 视觉与交互设计 | ui-design / web-design-expert |

本技能只回答「Python 语言与运行时层」的判断；越界时输出「本域外 + 建议调用方」而非硬答。

## 输出

`定位结果`：主方向 + 次方向 + 命中的知识条目路径列表。
