# branch（分支区）

本目录存放 python-expert 的流程节点细则。每个流程一个文件夹，文件夹名＝流程名。

## 内容

- [流程/](流程/流程.md)：顾问主流程十步（初始化→收尾）。

## 分支规则

1. 任一步骤缺输入时走该节点内声明的降级分支，不得跳步。
2. 取证探查失败（工具缺失/无权限）→ 记录中断并转「静态判断」分支，禁止伪造运行结果。
3. 跨领域问题（如并发×性能）→ 允许多领域并行检索，判断阶段合并结论。
4. 步骤细则变更须同步 [知识树](../references/知识树/知识树.md) 与 [resistance](../resistance/resistance.md)。
