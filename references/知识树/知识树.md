# 知识树（Python 专家领域）

根：Python 语言与生态的专家判断。拓扑规则：每个叶子必须能给出**可执行判据 + 权威出处 + 取证脚本**；
若某主题无法同时满足三者，则并入相邻叶子，不新开叶。当前九叶已覆盖语言层→运行时层→工程层→安全层，
再细分只会产生同一判据的别名，故判定为**不可再拓扑**。
